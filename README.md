This project analyzes customer churn data from IBM’s telecom dataset (sourced from Kaggle) to uncover insights into customer behavior, retention, and revenue impact.
The goal was to identify patterns that contribute to customer churn and visualize them through an interactive Power BI dashboard.

Tools used:

-> SQL – For data extraction, cleaning, and preprocessing

-> Power BI – For data modeling, visualization, and dashboard creation

-> DAX – For KPIs and calculated measures (Churn Rate, Average Tenure, etc.)

Key Insights:

-> Customers on month-to-month contracts have the highest churn rate.

-> Fiber optic users show higher churn compared to DSL users.

-> Electronic check payment users are more likely to churn.

-> Customers with longer tenure (>24 months) show strong loyalty.

-> Higher monthly charges correlate with higher churn.
